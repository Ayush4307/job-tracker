# job-tracker

Job tracker web app.

## Development

```bash
npm install
npm run dev
```

Other useful commands:

```bash
npm run build
npm run lint
```

## Tech Stack

- React + TypeScript
- Vite
- Supabase

## Vite Template Notes

This project was bootstrapped with the React + TypeScript + Vite template.

- React plugins: `@vitejs/plugin-react` or `@vitejs/plugin-react-swc`
- React Compiler is not enabled by default: https://react.dev/learn/react-compiler/installation
- ESLint is set up in `eslint.config.js` (you can enable stricter type-aware rules if needed)
